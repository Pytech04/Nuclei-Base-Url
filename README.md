# Nuclei-Base-Url

> Curated base URLs for Nuclei template testing and bug bounty recon.

[![GitHub](https://img.shields.io/badge/GitHub-Pytech04/Nuclei--Base--Url-blue)](https://github.com/Pytech04/Nuclei-Base-Url)

## 📋 Overview

A focused collection of base URLs optimized for use with [Nuclei](https://github.com/projectdiscovery/nuclei) vulnerability scanner. Designed for efficient template validation and reconnaissance workflows.

## 🚀 Usage

```bash
# Clone
git clone https://github.com/Pytech04/Nuclei-Base-Url.git
cd Nuclei-Base-Url

# Run nuclei against the list
cat urls.txt | nuclei -t cves/ -c 50
```
